Tessarr provides a Sabnzbd-compatible API for Arr applications to submit NZB files.

## How It Works

Arrs send NZB files to Tessarr's `/sabnzbd/api` endpoint. Tessarr:
1. Receives NZB file
2. Processes with Usenet providers
3. Streams/downloads content
4. Reports status back to Arr

## Configuration in Arrs

### Sonarr/Radarr

**Settings** → **Download Clients** → **+** → **Sabnzbd**

| Field | Value |
|-------|-------|
| **Name** | Tessarr Usenet |
| **Host** | `tessarr` (or IP) |
| **Port** | `8282` |
| **URL Base** | `/sabnzbd` |
| **Username** | Arr's host(`http://sonarr:8989`) |
| **Password** | Arr's token(gotten from Arr's General -> Token) |
| **Category** | `sonarr` / `radarr` |

Click **Test** → **Save**

## API Endpoints

Tessarr implements these Sabnzbd API endpoints:

| Endpoint | Purpose |
|----------|---------|
| `/sabnzbd/api?mode=addfile` | Add NZB file |
| `/sabnzbd/api?mode=queue` | Get queue status |
| `/sabnzbd/api?mode=history` | Get download history |
| `/sabnzbd/api?mode=config` | Get configuration |
| `/sabnzbd/api?mode=delete` | Remove from queue |

## Categories

Categories organize downloads:

```
/mnt/tessarr/
├── sonarr/
├── radarr/
├── lidarr/
└── custom/
```

Set in Arr's download client config.

## Status Mapping

Tessarr translates NZB processing status to Sabnzbd equivalents:

| Tessarr | Sabnzbd | Meaning |
|-----------|---------|---------|
| Processing | Downloading | NZB being processed |
| Streaming | Downloading | File accessible |
| Completed | Completed | Download finished |
| Failed | Failed | Error occurred |

### NZBs Not Processing

1. Verify Usenet providers configured: [Usenet Setup](../overview/)
2. Check logs for connection errors
3. Ensure provider has retention for the NZB

### Arr Shows "Unknown" Status

Tessarr may still be processing. Wait 1-2 minutes and refresh.

### Path Not Found

Ensure mount path matches between Tessarr and Arr:

**Docker Example:**
```yaml
services:
  tessarr:
    volumes:
      - /mnt/media:/mnt/media
  
  sonarr:
    volumes:
      - /mnt/media:/mnt/media
```

Then use `anime` or `4k` as category in Arr.

## Comparison to Native Sabnzbd

| Feature | Tessarr | Sabnzbd |
|---------|-----------|---------|
| NZB Processing | Direct NNTP streaming | Download + Extract |
| Disk Usage | Minimal (streaming) | Full file size |
| Speed | Instant start | Wait for complete download |
| PAR2 Repair | NA | Built-in |
| Post-Processing | Via Arr | Built-in scripts |

Tessarr is optimized for streaming; Sabnzbd for complete downloads.

## Switching from Sabnzbd

1. Add Tessarr as new download client in Arr
2. Set higher priority than Sabnzbd
3. Test with new downloads
4. Once stable, remove Sabnzbd client
5. Optionally disable Sabnzbd container

:::tip
Run both in parallel initially to ensure smooth transition.
:::
